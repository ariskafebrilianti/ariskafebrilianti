## 🚀 Featured Project

### 🏆 End-to-End Sales Data Management & Analytics System

**My main portfolio project | Data Analytics + Data Management**

🔗 [Explore the Repository](https://github.com/ariskafebrilianti/Sales-Data-Management-Analytics)

A hands-on end-to-end project designed to simulate how businesses collect, validate, manage, and analyze transactional sales data.

Instead of focusing only on creating a dashboard, I built a workflow that covers the data lifecycle, from raw data ingestion to analytical reporting.

### 🔍 What I Built

| Project Area | Implementation |
|---|---|
| 📥 Data Collection | CSV ingestion and staging workflow |
| 🧹 Data Profiling | Analyzed 2,823 sales transactions |
| ✅ Data Quality | Validation, consistency checks, and reconciliation |
| 🗄️ Database Design | Relational database using PostgreSQL & Supabase |
| ⚙️ ETL Process | Data transformation and database loading |
| 📊 SQL Analytics | 6 analytical SQL views for business performance |
| 🖥️ Application | Streamlit transaction management and dashboard |
| 🧪 Automated Testing | 13 automated test cases using Python unittest |
| 🤖 CI Automation | GitHub Actions workflow for automated testing |

### 💡 Key Features

- 📈 Sales performance and business KPI monitoring.
- 📅 Monthly sales trend analysis.
- 🛒 Product and customer performance analysis.
- 🌍 Geographic sales analysis.
- 💰 Deal-size performance monitoring.
- 🔄 Transaction input and management workflow.
- 🧪 Automated data validation and synthetic data testing.

### 🛠️ Tech Stack

`Python` `Pandas` `SQL` `PostgreSQL` `Supabase` `Streamlit` `Plotly` `Faker` `GitHub Actions`

**What I learned:** Building a complete data workflow requires more than writing queries or creating visualizations. Data quality, database structure, validation, and automation are equally important.
